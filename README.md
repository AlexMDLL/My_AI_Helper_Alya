# Аля — AI-компаньон на рабочем столе

Прозрачный оверлей с живым персонажем (Live2D / запечённые анимации), голосом, памятью и управлением компьютером. Живёт в углу экрана, не мешает работать: клики проходят сквозь прозрачные области, персонажа можно таскать мышкой.

## Что умеет

**Персонаж и анимации**
- Live2D-модели (Workshop VTube Studio, Alexia, Jane, Hiyori) на Cubism-рантайме.
- Интерактив: дыхание, покачивание, моргание, взгляд за курсором, липсинк, жесты.
- Запечённые видео-анимации (WebP, 60 fps): стойка, подмигивание, отрицание, удивление, радость, липсинк — с плавным кроссфейдом.
- Canvas-плеер с интерполяцией кадров, предзагрузкой и ленивой памятью.
- Режимы: Live2D / спрайты, «в куртке / без куртки» для модели VTS.

**Голос**
- Распознавание речи (sherpa-onnx, русский), wake-word «Аля», режим «слушать всегда».
- Синтез Silero v5 (Ксения, эмоции, ударения) с фолбэком на SAPI.
- Нормализация текста для TTS: числа словами с согласованием по роду и падежу, разворот сокращений (км/ч, Мбит/с, МБ/с, ГГц и т.д.), транслитерация латиницы.

**Мозг**
- Ollama (по умолчанию qwen2.5:7b-instruct), OpenRouter, DeepSeek API.
- Память: факты о пользователе, выученные правила, история чата.
- Инструменты: открыть приложение/сайт, громкость и медиа, скриншот, погода, время, PowerShell.
- Понимает команды: «закрой дискорд», «запусти контру» (Steam), «установи/отмени загрузку игры», «напиши в тг …» (UI-автоматизация), жесты («подмигни», «станцуй», «удивись»).

**Интерфейс**
- Чат в стиле мессенджера с пузырями, стримингом ответов и стоп-кнопкой.
- Настройки: характер, голос, модель, память, размер персонажа.
- Трей, перезапуск от администратора, автозапуск.

## Стек

Electron 35 · electron-vite · React 19 · TypeScript · PixiJS + pixi-live2d-display · Ollama · Silero TTS · sherpa-onnx · Python-сайдкар.

## Запуск

```bash
pnpm install
pnpm dev        # разработка
pnpm build      # сборка
```

Нужны: Node.js 20+, Python 3.10+ (для голоса), Ollama с моделью `qwen2.5:7b-instruct`.

### Голосовой сайдкар

```bash
cd voice
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## Что не входит в репозиторий

Из-за размера и лицензий в git не включены:
- `resources/live2d/` — Live2D-модели (скачиваются отдельно, у каждой своя лицензия);
- `resources/anim/` — запечённые кадры анимаций (генерируются кнопкой «Запечь анимации» или из видео);
- `voice/models/` — веса Silero (скачиваются при первом запуске);
- `node_modules/`, `out/`, `.venv/`.
